# ANIMA L0 paraphrases in Spanish, French and German. Same syntax as tools/anima_phrases.txt, read by
# tools/gen_anima_phrases.py into the same table. Each group's canonical is an ENGLISH phrase the English
# L0 already understands: ANIMA reads es/fr/de through English (components/nv_anima/anima_lang.c), and the
# reply comes back in the user's language. Accents and ñ/ü/ö/ß/ç fold to ASCII before matching, so write
# them naturally. A bare yes ("sí", "oui", "ja") is matched in anima_lang.c, not here: it only means
# something as the answer to a pending question. Opening/closing apps, numbers and arithmetic are composed by the glossary in anima_lang.c,
# not listed here.
