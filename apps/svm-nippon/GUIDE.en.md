# Nippon Safes, Inc.

## What it is for

Italian comedy adventure: three crooks, Dough, Donna and Dino, each with their own story in a crazy Japanese city. (Dynabyte, 1992.)

## How to use it

Pick the language on the Store page, then install. On first start the game downloads its original files from the ScummVM website (2 MB, Wi-Fi needed), checks them and starts; after that it starts straight away. The Back gesture stops the download: it resumes where it stopped. It runs on the ScummVM engine, which the Store installs together with the game.

Languages: IT / EN / FR / DE.

Licence: Freeware (Dynabyte). The files are the original ones, unmodified.

## Controls

| Action | Touch | Mouse | Keyboard | Gamepad |
|---|---|---|---|---|
| Walk / use | tap the spot | left button | – | A |
| Examine (right button) | press and hold, or two-finger tap | right button | – | B |
| Move the pointer | drag your finger | move | – | D-pad or left stick |
| Skip scene / dialogue | three-finger tap | – | Esc | X |
| Skip one line | – | – | . (period) | Y |
| Game menu (save, load) | – | – | F5 | Back / Select |
| ScummVM menu | Back gesture | – | Ctrl+F5 | Start |

USB or Bluetooth keyboards and mice work together with touch as soon as you plug them in. With a keyboard you can type save names.

## Saves

Each game saves in its own folder: from the ScummVM menu (Back gesture) choose **Save** or **Load**. Uninstalling the game deletes its saves.

## Common problems

- **The download stops**: check Wi-Fi and open the game again, it resumes where it stopped.
- **No sound**: another app (Music, for example) is using the speaker. Close it, sound comes back on its own within a few seconds.
- **I want another language**: pick it on the game's Store page. On the next start the game downloads the files of that language.
