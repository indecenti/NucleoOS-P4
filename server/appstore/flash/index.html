Install NucleoOS P4 on the Guition JC1060P470C

Installa NucleoOS P4 sulla Guition JC1060P470C

Custom OS for the Guition ESP32-P4 7" 1024×600 touchscreen (JC1060P470C_I_W). Flash it from this page — no ESP-IDF, no drivers to build.

OS personalizzato per il display Guition ESP32-P4 7" 1024×600 (JC1060P470C_I_W). Si installa da questa pagina: niente ESP-IDF, niente da compilare.

Check the chip revision first. This build runs on ESP32-P4 v0.x / v1.x silicon (the boards sold so far). esptool and the flasher log print it as “ESP32-P4 (revision v1.0)”. On a v3.x chip the bootloader refuses to start — nothing breaks, you can flash the stock firmware back.

Controlla prima la revisione del chip. Questa build gira su ESP32-P4 v0.x / v1.x (le board vendute finora). esptool e il log del flasher la mostrano come “ESP32-P4 (revision v1.0)”. Su un chip v3.x il bootloader non parte: non si rompe niente, puoi rimettere il firmware originale.

This browser can't talk to serial ports. Use Chrome or Edge on a desktop computer.Questo browser non accede alle porte seriali. Usa Chrome o Edge su computer. The flasher needs HTTPS.Il flasher richiede HTTPS.

Steps

Passi

  1. Plug the board into the computer with a data USB-C cable, on the port that shows up as a serial port (COMx on Windows, /dev/ttyUSB* or ttyACM* on Linux/macOS).
  2. Press Connect & install, pick the port, confirm. Tick Erase device on the first install to clear the stock firmware's settings.
  3. Wait a few minutes. If the connection times out, hold BOOT, tap RST, release BOOT, and try again.
  4. The board reboots into NucleoOS. Join Wi-Fi in Settings → Wi-Fi: from then on it updates itself over the air (a microSD must be inserted: updates are downloaded to the card first).
  1. Collega la board al computer con un cavo USB-C dati, sulla porta che compare come seriale (COMx su Windows, /dev/ttyUSB* o ttyACM* su Linux/macOS).
  2. Premi Collega e installa, scegli la porta, conferma. Al primo install spunta Erase device per cancellare le impostazioni del firmware originale.
  3. Aspetta qualche minuto. Se la connessione scade, tieni premuto BOOT, premi RST, rilascia BOOT e riprova.
  4. La board si riavvia in NucleoOS. Collega il Wi-Fi da Impostazioni → Wi-Fi: da lì in poi si aggiorna da sola via OTA (serve la microSD inserita: l'aggiornamento viene scaricato prima sulla scheda).

microSD card

Scheda microSD

The OS boots without a card, but OTA updates, apps, photos, music and the web companion need a FAT32 microSD. Apps and games install from the built-in Store. For the web companion (a desktop-like OS in your browser, served by the board) unzip nucleoos-p4-sdcard.zip to the root of the card.

L'OS parte anche senza scheda, ma aggiornamenti OTA, app, foto, musica e web companion richiedono una microSD FAT32. App e giochi si installano dallo Store integrato. Per il web companion (un desktop nel browser servito dalla board) scompatta nucleoos-p4-sdcard.zip nella radice della scheda.

Without the browser

Senza browser

Download the single factory image from the latest release and write it at offset 0 (this wipes the board's settings):

Scarica l'immagine factory unica dall'ultima release e scrivila all'offset 0 (cancella le impostazioni della board):

pip install esptool
esptool.py --chip esp32p4 -b 921600 write_flash 0x0 nucleoos-p4-<version>-jc1060p470c-factory.bin
